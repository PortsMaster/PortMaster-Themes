# The tutorial's theme, step by step

Each folder is a whole theme: the theme [CREATING_A_THEME.md](../../CREATING_A_THEME.md) builds,
as it is at the end of that step. Open them with PortMaster's theme server
(`serve.py --themes docs/tutorial`) to see each one, and change it.

`tools/render_docs.py` renders them for the guide's pictures (`docs/images/`).

These files (the `theme.json` files, `buttons.png` and `pointer.png`) are yours to copy into your
own themes, with no conditions: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
They aren't in PortMaster's theme list: only `themes/` is released.
